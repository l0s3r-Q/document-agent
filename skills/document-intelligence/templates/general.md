# 通用文档排版规范

## 页面
- Word 默认页边距：上下 2.54cm，左右 3.17cm

## 字体字号
| 要素 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 标题 | 黑体加粗 | 三号（16pt） | 居中 |
| 一级标题 | 黑体 | 三号（16pt） | 左对齐 |
| 二级标题 | 黑体 | 四号（14pt） | |
| 三级标题 | 黑体 | 小四（12pt） | |
| 正文 | 宋体 | 小四（12pt） | 首行缩进 2 字符 |

## 行距
- 1.5 倍行距

## 适用场景
报告、方案、总结、计划、会议纪要、说明书、工作邮件等无强制国标要求的文档。

## 建议结构
标题 → 导言/背景 → 主体章节（分节论述）→ 结论/建议 → 落款（单位/作者/日期）
